# StudentResultAnalysis


StudentResultAnalysis is a **Student Result Analysis & Prediction System** developed to analyze whether a student has **passed or failed in each subject and overall**, based on a **dynamic (changeable) threshold**.  
The project also displays results in **tabular format** and **visualizes how many students passed or failed** using graphs.  
This system is designed for **future enhancement using Machine Learning (Supervised Learning)** to **predict results for new students**.

---

## Project Type

 Academic Project  
 Developed as part of college/university coursework  
 Educational & learning-focused project

---

##  Features

-  Subject-wise **Pass/Fail analysis**
-  **Overall result calculation**
-  **Dynamic pass threshold** (can be changed anytime)
-  **Result displayed in tabular format**
-  **Visualization of how many students passed or failed**
-  Clear and simple result report
-  Ready for **Machine Learning integration**
-  Can be used to **predict results for new students (future scope)**

---

##  Result Visualization

- Displays student results in a **table format**
- Shows **graphical visualization (charts/plots)** of:
  - Number of students passed  
  - Number of students failed  
- Helps in **quick performance analysis**
